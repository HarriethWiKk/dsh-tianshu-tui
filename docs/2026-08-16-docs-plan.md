## 三、每篇大纲

### ADAPTER.md(工程价值最高,内容现成)
- 纯展示契约:不注册 prompt/工具/上下文面;用户输入是普通日志消息
- 服务面清单:必选(sessions/agents/agentDefaultModel)/ 可选(goals/subagents/
  memory/compact/tasks/skills/sessionProjections/workflowEngine/planMode)
- 事件订阅清单:session/*、workflow/*、subagent/*、approval/request、request/context 等
- 能力边界:agent/request 瀑布不能 mutate messages;workflow 事件 observe-only
  (无控制权);diff 审批无 patch 回传——记录"不可做"清单(防未来重复踩坑)
- bundle patch 内容(cordis.patch.yml 的 tui-runner 插入)
- 契约版本线:peer ^0.1.0-rc.6 / cordis ^4.0.1

### docs/getting-started.md
- 前置条件(Node ^22.19/>=24、pnpm、DEEPSEEK_API_KEY)
- 安装(`npx -y @deepseek-ai/dsh plugin --profile tui add ...`)+ 启动 + 首屏解读
- 常见问题:ERR_FS_EISDIR / DSH_TUI_SKIP_UPDATE / 自更新提示 / 干净目录启动

### docs/architecture.md
- src 目录地图(engine/format/controllers/adapter/render/ui 各层职责)
- 数据流:会话事件 → adapter 折叠 → transcript → 渲染(滚动区 + live 区)
- 投影层(projection-layer.md 摘要)、控制器(question/approval/btw/session-manager)
- overlay 体系、主题解析、LSP 桥(纯展示本地)

### docs/configuration.md
- TuiRunnerConfig 全字段(stdin/stdout/initialSessionId/editorKey/vimEnabled/
  vision/workflowHistoryLimit/lsp)
- 环境变量(DSH_TUI_SKIP_UPDATE)
- 运行时:/config 面板(settings/permission/credentials)、/theme、/density、/preset

### docs/interaction.md
- 快捷键全表(分组:会话/输入/面板/overlay)
- 命令全表(28 条,分组:会话/模型/面板/记忆/诊断)
- 交互模式:slash 菜单、@ 补全、选择器(issue #31)、审批卡、提问面板、plan 循环

### docs/themes.md
- 16 个内置主题表 + 预览描述、/theme、custom:<name>
- 终端自动检测与 16 色降级、ascii 降级

### docs/plugins.md
- 伴生插件:vision-ask(ask_image)、lsp(社区 omdsh-dev/dsh-lsp)
- 扩展点:slash 注册表(tui.commands 服务)、overlay 注册
- 服务依赖表(必选/可选 → 缺失行为)

### CONTRIBUTING.md / docs/contributing.md
- PR 规范(聚焦、中英标题、动机/改动/验证)、issue 规范
- 验证矩阵:typecheck(含 vision-ask)+ npm test 全量 + CI 同款
- 文档规范:i18n 配对(README 哈希机制)、SOURCE-MAP 护栏(新文件必须补条目)
- 引用 AGENTS.md 纪律

### docs/vscode.md
- 内置终端运行 dsh、字体/终端设置建议、无官方扩展的现状说明

## 四、实施决策点(需用户确认)

- **D1 中英配对范围**:全 7 篇中英成对 vs 先中文(英文后续补)。参考项目全成对;
  工作量约 ×2。建议:核心 4 篇(快速开始/架构/配置/交互)中英成对,其余先中文。
- **D2 配对机制**:README.i18n.yaml 目前只覆盖 README 对。新增文档的 en 配对
  是否沿用哈希机制(扩展 yaml)还是人工同步(轻量)。
- **D3 screenshots**:需要用户提供真实截图(首屏/工作状态行/面板/选择器),
  我只能搭目录与 README 引用占位。
- **D4 install.sh**:本项目安装走 `dsh plugin add`,脚本价值低于参考项目
  (他们带直达命令 dsh-tui)。建议不做,或用 scripts/dev.sh 承担开发启动说明。
- **D5 README 精简**:建议不动(功能全表是特色),只加文档索引段。
