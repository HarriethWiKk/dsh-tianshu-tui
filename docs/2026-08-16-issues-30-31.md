## #30 — 审计修复(先做,小而独立)

WhaleHarness 规则(来自 audit-fixes.html):
- 版本必须纯 `^\d+\.\d+\.\d+$`,prerelease 被拒——**发布流程问题**,rc 版本不提交
  审计即可,正式版自然通过,代码无需改。
- 用 child_process 必须在 package.json 声明 `"dsh": {"runtime": "host"}`,否则
  RED-LINE;动态形式(exec/execSync 走 shell)即使声明也 RED-LINE,须换固定
  argv 形式(execFileSync/spawnSync 无 shell,降级为 warning)。

本仓 subprocess 4 处(审计计数):
1. `src/ui/app.ts` gitBranch: `execSync('git rev-parse --is-inside-work-tree')`
2. `src/ui/app.ts` gitBranch: `execSync('git rev-parse --abbrev-ref HEAD')`
3. `src/ui/app.ts` gitDirtyCount: `execSync('git status --short')`(A3 新增)
4. external-editor(editor 启动,待确认形态)

**改法**:
1. package.json `"dsh"` 加 `"runtime": "host"`(保留 bundle.patch)
2. 三处 git 调用 `execSync` → `execFileSync('git', [...])`(固定 argv,无 shell)
3. external-editor 若为固定 spawn 形态则无需改(审计只看动态形式)

**测试**:gitBranch/gitDirtyCount 现有测试不受影响(行为等价);typecheck + 相关 spec + 全量。

## #31 — 交互式选择器(主工作)

诉求:主题/模型/session 切换做成「回车后上下键选择」,替代命令参数输入
(终端里输命令易错、不便复制粘贴)。

**数据源(已核实)**:
- 模型:`ctx.llm.listProviders()`(LlmProviderInfo[])+ `listModels()`(adapter 通告)
- 主题:`THEME_NAMES`(本仓 theme.ts)
- 会话:`listSessions(ctx)`(/session list 同源)

**方案**:新增 PickerOverlay(复用现有 overlay 基础设施:OverlayController +
overlay-engine,与 command-palette/keymap/search 同构):
- 打开:命令无参调用时打开(`/model`、`/theme`、`/session` 无参数 → 选择器;
  有参数仍走原路径,不破坏现有用法)
- 交互:↑/↓ 移动、PageUp/PageDown 翻页、Enter 确认、Esc 取消、`q` 关闭
- 渲染:标题 + 选项列表(当前值高亮标记)+ footer 键位提示;窄宽截断
- 确认动作:模型 → saveSelection + switchLiveModel(与 /model 同路径);
  主题 → setTheme;会话 → switchSession

**文件**:
- 新 `src/engine/picker-overlay.ts`(或 src/picker/):选择器状态机 + 渲染(纯函数)
- `src/ui/app.ts`:注册 overlay 实例、命令接线(/model /theme /session 无参打开)、
  键盘转发
- `src/commands/registry.ts`:三个命令 run 无参分支改为打开选择器(经 deps 回调)

**测试**:
- picker 纯函数:选项投影(高亮/截断/空态)
- app.spec:无参命令打开 overlay、↑↓ 选择、Enter 确认触发对应动作、Esc 取消
- commands.spec:有参命令行为不变
